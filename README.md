3. Introduction to Power BI course from DataCamp, completed 9/26/2026.
In Flex Assignment 4, I built a separate "Profitability" calculated field in Tableau just to color my bars red or grey based on positive or negative net contribution. Power BI does this automatically through its formatting pane, no formula required. Next time I'd use Power BI's built-in conditional formatting for a simple case like this, since it does the same job faster and I'd only reach for a manual calculated field if the coloring logic got more complex than a simple threshold.
Link to my Tableau profile: https://public.tableau.com/app/profile/anastasiia.semenova2944/viz/PowerBITrainingCertifications_17904864317360/PowerBIStory

4. Introduction to DAX in Power BI course from DataCamp, completed 10/01/2026.
In the Excel sheet I built for Flex Assignment 4, I pulled Order Year and Order Month out into their own columns by hand just so I could summarize a four-year file by period. In DAX, once you have a real date table marked as the model's date table, time-intelligence functions handle those period comparisons automatically, without the need to pre-extract and hardcode year or month breakdowns for every new calculation. Next time I'd set up a date table and use DAX's time intelligence instead, since it adapts to any filter context automatically rather than covering only the slices I thought to pre-build.
Link to my Tableau profile: https://public.tableau.com/app/profile/anastasiia.semenova2944/viz/PowerBITrainingCertifications_17904864317360/PowerBIStory

5. Data Visualization in Power BI course from DataCamp, completed 10/13/2026.
I have had enough practice with Power BI and other tools to begin business intelligence work at Southwest, and exposure to each has helped me revise my earlier approaches. My Flex 4 Account Scatter plots each of the 793 accounts’ net contribution against revenue but colors points only by tier; with conditional formatting on average discount in Power BI, Marcus would see which heavy-discount accounts to act on first. Likewise, my Order Data sheet counts orders with a COUNTIF helper column that only works because each order has one customer, whereas a DISTINCTCOUNT measure stays accurate at any grain.
Across tools, I would divide the work by what each does best. Excel is where I would start, for initial data cleanup and for getting familiar with a dataset. Tableau is where I would build visuals, since I find it the most intuitive for exploration and for explanatory charts like my Flex 4 Applied Chart. Power BI is where I would build recurring reports that many people rely on, because measures are defined once in DAX and the data refreshes on a schedule. My main gap is that I have only used Power BI Desktop on a virtual desktop with fictional data, and I have never worked with real company data or published and maintained a report. To close it, I would look for more opportunities to practice and find a way to work on a Windows computer, since Power BI Desktop runs only on Windows.
Link to my Tableau profile: https://public.tableau.com/app/profile/anastasiia.semenova2944/viz/PowerBITrainingCertifications_17904864317360/PowerBIStory
